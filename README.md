# block_data_flex_editor

Moodleのデータベースモジュール（mod_data）に保存されたエントリを、フィールドの役割（固定列／移動列など）を自由に設定して効率的に編集するためのブロックプラグインです。

`block_data_timetable_editor`（時間割専用エディタ）を汎用化した後継プラグインです。時間割に限らず、当直表・シフト表・発表順管理など「固定する列」と「入れ替える列」が混在するデータベースであれば同じUIで編集できます。

## 概要

mod_dataのフィールド**型**（`date` / `menu` / `textarea` / `text`）を参照して編集UIを自動的に決定するため、フィールド名のハードコードがありません。どのデータベースに対しても、フィールド一覧を取得して役割を割り当てるだけで同じ編集体験を提供します。

### 主な機能

- **フィールド型に応じた自動UI生成**：date型はdate input、menu型はselect、textarea型はtextarea、それ以外はtext inputに自動対応
- **フィールドの役割設定**：固定列・移動列・初期ソートキー・連番フィールド・グループフィールド・連番ソートキーを画面上で自由に割り当て
- **ドラッグ&ドロップによる並び替え**（移動列を行単位で移動）
- **D&Dモード切替**：挿入（押し出し）／スワップ（入れ替え）
- **↑↓ボタン**による隣接行の即時スワップ
- **末尾へのコマ追加・チェックボックスによる削除**
- **プレビュー確認**：更新・追加・削除の差分を保存前に表示
- **連番振り直しオプション**：指定したソートキー順に連番フィールドをゼロから採番（任意設定）
- **フィールド名による動的解決**：フィールドIDをフィールド名から実行時に取得するため、環境差異の影響なし

## 動作要件

- Moodle 4.0 以上
- 任意のデータベースモジュール（mod_data）　※フィールド名・フィールド数は自由

対象データベースの各フィールドは、以下の型のいずれかであれば自動的に適切な編集UIが割り当てられます。

| フィールド型 | 編集UI |
|---|---|
| `date` | date input（Unixタイムスタンプ変換を自動処理） |
| `menu` | select（選択肢はデータベース側の設定から自動取得） |
| `textarea` | textarea |
| `text` / `number` / その他 | text input（フォールバック） |

## インストール

1. Moodleの `blocks/` ディレクトリにクローンまたは展開します：
   ```
   git clone https://github.com/yasada0819/moodle-block_data_flex_editor.git /path/to/moodle/blocks/data_flex_editor
   ```
   またはZIPをダウンロードして `blocks/data_flex_editor/` として配置します。

2. 管理者でMoodleにログインし、**サイト管理 → 通知** からインストールを完了します。

## 設定

### 1. ブロックの追加とデータベースIDの設定

1. コースページ（編集モード）に **データフレックスエディタ** ブロックを追加します。
2. ブロック設定を開き、対象データベースモジュールの **ID（dataid）** を入力します。
   - IDはデータベースを表示したときのURLで確認できます：`?d=XXXX`
3. 必要に応じて **テキストフォーマット**（textareaの保存形式）と **最小行数** を設定します。
4. 設定を保存します。

### 2. フィールド役割の設定

1. ブロック上の **「フィールド役割の設定」** をクリックします（専用ページ `settings.php` に遷移）。
2. データベースのフィールド一覧が表示されます。各フィールドについて、以下の役割から選択します。

| 役割 | 意味 |
|---|---|
| 固定列（直接編集） | テーブル上で常に同じ行に表示され、直接編集する列（日付・時間・区分など） |
| 移動列（D&Dで入れ替え） | ドラッグ&ドロップまたは↑↓ボタンで行単位に入れ替える列（担当者・内容など） |
| 初期ソートキー | エディタを開いたときの初期表示順を決めるフィールド |
| 連番フィールド（振り直し対象） | 「連番を振り直す」オプションで採番されるフィールド |
| グループフィールド（区分別カウント） | 区分ごとにカウントしたい場合のグループ化フィールド（任意） |
| 連番ソートキー（振り直し時の並び順） | 振り直し実行時に、どの順番で並べ替えてから採番するかを決めるフィールド（複数指定可） |
| 使用しない | 編集テーブルに表示しない |

3. **「保存する」** をクリックすると設定が反映されます。

> フィールド役割の設定は素のHTMLフォーム（JSなし）で動作します。Moodleのブロック設定モーダルではなく専用ページを使うことで、日本語フィールド名やモーダル内のJS実行タイミングの問題を回避しています（詳細は設計メモを参照）。

### 3. エディタを開く

ブロック上の **「エディタを開く」** をクリックすると編集画面に遷移します。

> ブロックはログインユーザー（レコードの作成者）でエントリを自動フィルタします。科目アカウントなど専用アカウントでログインすると、そのアカウントが作成したエントリだけが表示されます。

## 使い方（エディタ画面）

1. テーブル上でエントリを編集します：
   - **固定列**：入力欄・セレクトボックス・日付ピッカーなど、フィールド型に応じたUIで直接編集
   - **移動列**：D&Dまたは↑↓ボタンで行移動
2. **D&Dモード**を選択します：
   - **挿入（押し出し）**：ドロップ位置に割り込み、間の行が押し出されます
   - **スワップ（入れ替え）**：ドラッグ元とドロップ先の移動列を入れ替えます
3. **コマを追加**する場合：テーブル下部の **「＋ 末尾にコマを追加」** をクリックします。
4. **コマを削除**する場合：行右端のチェックボックスにチェックを入れます（行が赤くなります）。
5. **「プレビューを確認する」** をクリックして変更内容を確認します。
6. 連番フィールドを設定している場合、必要に応じて **「連番を振り直す」** にチェックを入れます。
7. **「保存する」** をクリックして一括保存します。

## 設計の背景

`block_data_timetable_editor`（時間割専用の編集ブロック）を、時間割以外のデータベースにも使えるよう汎用化する目的で開発しました。

- **フィールド型ベースの自動UI決定**：フィールド名のハードコードを排除し、`date` / `menu` / `textarea` / `text` の型情報だけで編集UIを自動的に決定
- **フィールド役割の設定を専用ページに分離**：ブロック設定モーダル内でのAJAX処理はJSタイミングの問題が起きやすいため、素のHTMLフォームで動作する専用ページ（`settings.php`）に切り出し
- **`$_POST` 直接参照によるサニタイズ**：`optional_param_array(..., PARAM_ALPHA)` は日本語などマルチバイトのフィールド名をキーごと削除してしまうため、`$_POST` を直接参照し値のみサニタイズする方式を採用
- **フィールド名による動的解決**：本番・開発環境でフィールドIDが異なる問題を回避するため、フィールド名からIDを実行時に解決する（`block_data_timetable_editor` から引き継いだ設計方針）

### `block_data_timetable_editor` との関係

`block_data_timetable_editor` は時間割データベース専用（フィールド名がハードコード）のプラグインとして先に作成されました。本プラグインはその設計・実装を踏襲しつつ汎用化した後継版です。時間割用途を含め、`block_data_timetable_editor` が担っていた役割はフィールド役割の設定次第で本プラグインに統合できます。
